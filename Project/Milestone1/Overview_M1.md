# Urban Pulse – Smart City Mobility Intelligence Platform

## Project Overview

**Urban Pulse** is a Smart City Mobility Intelligence Platform designed to analyze transportation-related data from multiple sources.

The project uses **Power BI** to create interactive dashboards that help understand city mobility patterns and support **data-driven decision-making**.

---

## Main Objective

The main objectives of the Urban Pulse project are:

* Collect data from different sources
* Clean and preprocess the data
* Analyze the collected data
* Build interactive dashboards
* Generate meaningful insights for better decision-making

---

## Data vs Information

As part of Milestone 1, the project covers the basic concepts of **Data and Information** and different types of data.

### Types of Data

* **Structured Data**
* **Unstructured Data**
* **Semi-Structured Data**

---

## Data Sources

Urban Pulse works with data from multiple sources, including:

1. **Geographic Data**
2. **Transportation Data**
3. **Weather Data**
4. **Ride-Hailing Data**
5. **Demographic Data**

These different data sources provide information that can be used to understand various aspects of city mobility.

---

## 🧹 Data Preprocessing

Data preprocessing is performed using **Power Query** in Power BI.

The preprocessing steps covered in Milestone 1 include:

* Importing datasets
* Removing duplicate records
* Handling missing values
* Changing data types
* Filtering unnecessary rows

These steps help prepare the data for further analysis and visualization.
